# الأمن — Amin-Lab -Pro🔬

## نموذج التهديد

النظام مصمّم لمختبر مدرسي على شبكة محلية موثوقة. أكبر المخاطر الواقعية:

1. كلمات مرور ضعيفة أو مسرّبة (لا توجد كلمات افتراضية في الكود).
2. تشغيل الخادم مكشوفاً على الإنترنت بدون HTTPS.
3. فقدان البيانات بسبب غياب النسخ الاحتياطي.
4. وصول أستاذ إلى بيانات أستاذ آخر (مُعالَج في طبقة الصلاحيات).

## المصادقة

- كلمات المرور تُخزَّن بـ **scrypt** (`N=16384` الافتراضي من Node) مع ملح عشوائي
  16 بايت لكل مستخدم، في الشكل `scrypt$<salt>$<hash>`.
- المقارنة تتم بـ `timingSafeEqual` (لا تسريب زمني).
- الجلسة رمز موقّع HMAC-SHA256: `base64url(payload).signature`، يحوي
  `sub`, `username`, `role`, `exp`. لا يُخزَّن أي شيء في الخادم.
- المدة الافتراضية 8 ساعات (`SESSION_TTL`). تسجيل الخروج يمسح الرمز من العميل.
- **مهم:** `APP_SECRET` إلزامي في الإنتاج. ولّده مرة واحدة واحفظه في متغيرات بيئة الخادم:
  ```bash
  node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
  ```
  لا تكتبه في الكود ولا في Git. تغييره يُبطل كل الجلسات القائمة ويوقف قبول المفاتيح المشتقة القديمة.

## كلمات المرور الأولى

- لا توجد كلمات مرور افتراضية. عند أول تشغيل على قاعدة فارغة:
  - تُقرأ `ADMIN_PASSWORD` و`TEACHER_PASSWORD` إن كانتا مضبوطتين،
  - وإلا تُولَّد كلمتان عشوائيتان (24 حرفاً) وتُكتبان في `data/first-run-credentials.txt`
    بصلاحيات `600`، مع تحذير في السجل **بدون طباعة القيم**.
- انقل بيانات الملف إلى مدير كلمات المرور ثم احذف الملف.
- تغيير أي كلمة مرور: `npm run set-password -- <username>` — تُكتب النتيجة في
  `data/credentials.txt` (صلاحيات `600`) ولا تُطبع في الطرفية.

## الصلاحيات

| العملية | admin | teacher |
|--------|:-----:|:-------:|
| قراءة الجرد | ✅ | ✅ |
| إضافة/تعديل/حذف صنف | ✅ | ❌ |
| إنشاء إعارة | ✅ | ✅ (لنفسه) |
| إرجاع/حذف إعارة | ✅ | فقط إعاراته |
| رؤية إعارات الآخرين | ✅ | ❌ |
| تسجيل فحص QC | ✅ | ✅ |
| إدارة الحسابات والقاعات | ✅ | ❌ |

التحقق يتم في `middleware/auth.ts` (`requireAuth`, `requireAdmin`, `canAccessTeacher`)
وليس في الواجهة فقط — الواجهة تُخفي الأزرار لكن الخادم هو المرجع.

## حماية المدخلات

- `middleware/validation.ts` يتحقق من النوع والطول والمدى والتواريخ والأوقات،
  **ويحذف** أي حقل غير معرّف قبل وصوله للمتحكم.
- كل استعلامات SQLite تستعمل معاملات مربوطة (`?`) — لا تركيب نصوص.
- `express.json({ limit: '1mb' })` يحدّ حجم الطلب.
- الواجهة تُهرّب كل النصوص المعروضة عبر `App.escape` (منع XSS).
- رموز الجلسة لا تُسجَّل في السجلات؛ `logger` يسجّل المسار والحالة فقط.

## ترويسات الأمن المُضافة

```
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
Referrer-Policy: same-origin
```

## HTTPS

الخادم لا ينهي TLS. ضعه خلف Nginx/IIS مع شهادة (Let's Encrypt أو شهادة المؤسسة).
بدون HTTPS، رمز الجلسة ينتقل نصاً صريحاً على الشبكة.

## البيانات والنسخ الاحتياطي

- كل البيانات محلية في `data/` — لا إرسال لأي خدمة خارجية، ولا تحليلات.
- قاعدة البيانات في وضع WAL؛ خذ النسخة عبر `npm run backup` أو بعد إيقاف الخدمة.
- احتفظ بنسخة خارج الجهاز (قرص شبكي/سحابة المؤسسة) أسبوعياً.
- ملفات `data/` مستثناة من Git ومن حزمة ZIP (`scripts/create-package.mjs`).

## Service Worker

`client/src/sw.js` لا يخزّن أي طلب يبدأ بـ`/api/` — بيانات الإعارة والتقارير لا
تُحفظ في الكاش، حفاظاً على الخصوصية ومنعاً لعرض بيانات قديمة.

## الإبلاغ عن ثغرة

راسل مسؤول النظام داخلياً مع وصف المشكلة وخطوات إعادة إنتاجها. لا تُنشر التفاصيل
قبل إصدار إصلاح.
